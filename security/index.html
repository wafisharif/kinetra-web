Security

Last updated: November 2026
In one paragraph: video, sign-up, and sign-in traffic travel over HTTPS; a recorded video is deleted from the server immediately after processing and never stored long-term; almost everything else Kinetra records stays only on your own device; dashboard passwords are hashed before they're ever stored; and there is no advertising SDK and no third-party tracking of any kind. Full detail on all of this is in the Privacy Policy -- this page is a shorter, security-focused summary of the same facts, plus how to report a problem.

1. Data in transit

A recorded video, and any sign-up or sign-in request to the web dashboard, is sent over HTTPS. Kinetra does not offer an unencrypted way to submit this data.

2. Video handling

A video you record is uploaded solely to run pose estimation and compute your result. It is deleted from the server's disk immediately after processing, whether the analysis succeeds or fails, is never viewed by a human, never used to train any model, and never shared with, sold to, or disclosed to any third party.

3. What's stored where

Your session results, calibration, and preferences are stored only in the app's local storage on your own device -- not on Kinetra's server, and not backed up automatically. The one exception is the optional web dashboard: creating an account there means your name, email, and a hashed password are stored on Kinetra's server, and turning on Web Dashboard Sync sends a copy of your sessions, check-ins, and calibration there too. See the Privacy Policy for the complete breakdown.

4. No ads, no third-party trackers

Kinetra contains no advertising SDK and no third-party analytics enabled by default, and does not sell or share data with data brokers. An optional, off-by-default crash-reporting integration exists for diagnosing bugs; it reports only error details, never movement data, video, or personal information.

5. Reporting a security issue

If you believe you have found a security vulnerability in Kinetra -- the app, the website, or the backend -- email wafi@kinetraapp.com with details and, if possible, steps to reproduce it. Please allow time to address it before disclosing it publicly.

6. Contact

Questions about this page, or about the full data-handling detail: wafi@kinetraapp.com. See also the Privacy Policy and Terms of Service.
